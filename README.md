# 🍕 Pizza Ordering App

A full-stack pizza ordering web application that allows users to browse pizzas, view products, add items to a cart, and place orders.

## 🚀 Features

- 🍕 Browse pizza products
- 📋 View product details
- 🛒 Add products to cart
- 🔢 Manage cart quantities
- 👤 User authentication
- 📦 Order management
- 🗄️ MySQL database integration
- 🔗 REST API integration
- 📱 Responsive user interface

## 🛠️ Technologies Used

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3

### Backend
- Node.js
- Express.js

### Database
- MySQL

- npm
